# Aviso de privacidad de NextHelp para Android

Responsable: equipo de NextHelp (Zeedatik). Contacto: soporte@zeedatik.com.

## Asistente

En el modo de demostración, las preguntas se procesan en el dispositivo. El texto y las respuestas se mantienen en memoria mientras la pantalla del asistente está abierta.

Si pulsas **Dictar**, NextHelp abre el servicio de reconocimiento de voz del dispositivo y recibe el texto que el servicio devuelve. NextHelp solicita que el dictado funcione sin conexión. El servicio de voz decide cómo procesar el audio y puede enviarlo a su proveedor según su configuración y su propia política de privacidad. NextHelp no recibe ni guarda el audio.

Si configuras una API y pulsas **Responder**, NextHelp envía la pregunta, un identificador fijo de demostración y el token opcional al servidor que hayas elegido para obtener una respuesta. El operador de ese servidor determina cómo usa y conserva esos datos. El token se mantiene en memoria mientras la pantalla del asistente está abierta y no se guarda de forma persistente.

## Datos guardados y eliminación

El juego guarda el mejor puntaje y el ciclo máximo en las preferencias de la aplicación. Android puede incluir estas preferencias en las copias de seguridad del dispositivo si están habilitadas. Puedes eliminar el progreso local borrando los datos de NextHelp desde Ajustes de Android.

NextHelp para Android no crea cuentas ni integra publicidad o herramientas de analítica. Para consultas de privacidad o solicitudes sobre tus datos, escribe a soporte@zeedatik.com. Si enviaste información a una API configurada por ti, consulta también al operador de ese servicio sobre su conservación y eliminación.
